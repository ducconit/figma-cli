# figma-cli `fm`

> High-Performance, Zero-Dependency Figma Extraction Engine & Universal AI Agent Skill

- **Zero Runtime Dependencies**: Single static binary compiled with `CGO_ENABLED=0`
- **Token Efficiency**: Tree DSL cuts token consumption by up to **80%** compared to raw JSON
- **Google Stitch**: Native `DESIGN.md` export compatible with `@google/design.md` lint
- **Multi-Agent Ready**: Built-in skill symlinks for Antigravity, Claude Code, Cursor, OpenCode, Codex
- **Pure-Go Image Pipeline**: 2-stage streaming crop & download for SVG, PNG, GIF
